# MyGallery Roadmap

Цей документ описує потенційні нові функції та покращення для майбутніх версій MyGallery. Завдання розбиті за пріоритетом.

## 🚀 Високий пріоритет (High Priority - UX & Core)

- [ ] **Підтримка Відео (MP4/WebM)**: Можливість завантажувати відео з автоматичною генерацією обкладинок (через `FFmpeg` або HTML5 Canvas) та власним плеєром.
- [ ] **Геолокація та Карти**: Використання EXIF GPS-координат для відображення міні-карти (OpenStreetMap/Leaflet) поруч із фотографією.

## ⚡ Середній пріоритет (Medium Priority - Features & Performance)

- [ ] **Розумні Альбоми (Smart Albums)**: Автоматичне групування фотографій за датою зйомки (місяць/рік) або домінуючим кольором без необхідності ручного додавання в альбом.
- [ ] **Повна підтримка WebP/AVIF**: Дозвіл завантажувати файли `*.webp` та `*.avif` як оригінали, а також їх конвертація і відображення.
- [ ] **Водяні знаки (Watermarking)**: Налаштування в адмін-панелі для автоматичного накладання текстового або графічного водяного знака на публічні `large` зображення (зберігаючи оригінали чистими).
- [ ] **Базове REST API**: Створення JSON-ендпоінтів (`/api/v1/photos` тощо) з доступом по токену для можливості розробки стороннього мобільного додатку-гляделки.

## 💡 Низький пріоритет (Low Priority - Nice to Have)

- [ ] **Багатокористувацький режим (Multi-User)**: Додавання системи ролей (Admin, Viewer) та ізольованих галерей для різних користувачів замість одного єдиного адміністратора.
- [ ] **Хмарні бекапи (S3 / B2)**: Налаштування скрипту `tools/backup.php` для автоматичного вивантаження архівів на AWS S3, Cloudflare R2 або Backblaze B2.
- [ ] **Система коментарів/вподобань**: Можливість відвідувачам залишати лайки чи базові коментарі до публічних фото (із захистом від спаму).
- [ ] **Розпізнавання облич / об'єктів**: Експериментальна інтеграція зовнішніх AI API (наприклад, Google Cloud Vision) для автоматичної генерації тегів.

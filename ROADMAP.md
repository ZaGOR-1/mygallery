# Дорожня карта розвитку проєкту (Roadmap)

Цей файл описує план подальшого розвитку MyGallery. Усі завдання враховують архітектурні принципи проєкту: жодних важких фреймворків (Laravel, Symfony), жодних JS-фреймворків (React, Vue), лише чистий, безпечний та швидкий PHP/JS.

## 🚀 P1: Найвищий пріоритет (Адміністрування та UX)

### 1. Інтерфейс "Кошика" (Trash Bin UI)
**Мета:** Додати веб-інтерфейс для керування видаленими файлами.
- **Деталі:** Наразі видалені фотографії потрапляють у `storage/trash` і можуть бути відновлені лише через CLI-скрипт `recover_trash.php`. Потрібна сторінка в адмінці "Кошик" для перегляду, відновлення або остаточного видалення фотографій.
- **Складність:** Середня.

### 2. Сортування альбомів (Custom Album Ordering)
**Мета:** Дозволити адміністратору визначати порядок відображення альбомів на публічній сторінці.
- **Деталі:** Додавання поля `sort_order` у таблицю `albums`. В адмінці — можливість міняти порядок кнопочками "Вгору/Вниз".
- **Складність:** Низька.

## 🛠 P2: Середній пріоритет (Керування контентом)

### 3. Приватні альбоми (Hidden/Private Albums)
**Мета:** Приховувати певні альбоми від публічної галереї.
- **Деталі:** Додати прапорець `is_private` до таблиці `albums`. Такі альбоми не показуються на головній сторінці, але адміністратор може їх бачити в адмінці або генерувати "Share Links" для доступу друзям.
- **Складність:** Середня.

### 4. Витягування домінантного кольору (Dominant Color Placeholder)
**Мета:** Покращити сприйняття галереї на повільному інтернеті.
- **Деталі:** Під час завантаження фото аналізувати його та зберігати основний колір (наприклад, `#a8b4c1`) у БД. Цей колір використовуватиметься як фон для `<img>` до моменту повного завантаження картинки.
- **Складність:** Середня (GD дозволяє легко зменшити фото до 1x1 пікселя для отримання кольору).

## 🌟 P3: Розширені фічі (Нові формати, швидкість та шарінг)

### 5. Підтримка WebP / AVIF (Next-Gen Images)
**Мета:** Зменшити вагу зображень для користувачів без втрати якості.
- **Деталі:** Оскільки PHP 8.4 + GD чудово підтримують сучасні формати, система може генерувати WebP/AVIF копії поруч із JPEG і віддавати їх через тег `<picture>`. Оригінал усе одно зберігається як JPEG.
- **Складність:** Висока.

### 6. Відображення локацій (GPS Map Integration)
**Мета:** Якщо в EXIF є координати (GPS), показувати на сторінці фотографії невелику карту або посилання на Google Maps/OpenStreetMap.
- **Деталі:** Потребує налаштувань приватності (адмін повинен мати змогу вимкнути читання GPS для певних фото).
- **Складність:** Середня.

### 7. Завантаження альбому одним архівом (Download as ZIP)
**Мета:** Спростити обмін фотографіями для користувачів.
- **Деталі:** Кнопка "Завантажити альбом" на публічній сторінці альбому, яка на льоту (через `ZipArchive`) формує архів із `large`-версій фотографій.
- **Складність:** Середня.

### 8. Підтримка відео (Basic Video Support)
**Мета:** Зберігати не лише фото, а й короткі відео з камери.
- **Деталі:** Завантаження `.mp4` та `.mov`, генерація мініатюри-постеру (через виклик `ffmpeg` у фоні або ручне завантаження обкладинки адміністратором).
- **Складність:** Висока.
